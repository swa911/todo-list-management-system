
# To-Do List and Task Management System

## Project Description
A web-based application that helps users
organize and manage their daily tasks.

## Objectives
- Manage daily tasks.
- Track completed and pending tasks.
- Improve productivity.

## Features
1. Add Task
2. Edit Task
3. Delete Task
4. Search Task
5. Mark Task as Completed
6. Filter Tasks
7. Local Storage

- HTML
- CSS
- JavaScript
- Git
